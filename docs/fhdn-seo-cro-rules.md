# FHDN SEO/CRO Build Rules — St Augustine On The Water

> **For agents:** Read this document before making content, layout, SEO, or conversion changes to this site. When in doubt, ask: *Does this make it easier for a visitor to find, trust, compare, and book a St. Augustine water experience?*

This site is an affiliate tourism booking site for St. Augustine, Florida.

**Primary goal:** Convert organic visitors into FareHarbor Distribution Network (FHDN) booking clicks.

This is not a brochure site. Every major page should help move users toward a monetizable booking page.

## Core business model

The site earns affiliate commissions by sending visitors to book water-based tourism experiences through FHDN.

**Priority revenue categories:**

1. Private boat rentals
2. Captained boat rentals / charters
3. Pontoon rentals
4. Sunset cruises
5. Dolphin tours
6. Fishing charters
7. Nights of Lights boat tours
8. Other St. Augustine water experiences

## Brand positioning

**Brand name:** St Augustine On The Water

**Brand feel:** Premium, trustworthy, local, helpful, tourism-focused.

**Avoid:** Spammy affiliate tone, overhyped claims, keyword stuffing, fake urgency, generic AI copy.

The site should feel like a real local water-experience guide, not a thin affiliate website.

## Conversion rules

Every important page should have a clear next step.

**Preferred CTA language:**

- Compare Options
- View Availability
- See Pricing
- Check Availability
- Find Your Perfect Boat Day
- Compare Water Experiences
- Book This Experience

**Avoid weak CTAs:**

- Learn More
- Explore
- Discover
- Read More

**Use commercial intent language naturally:**

- compare top-rated experiences
- view pricing and availability
- find trusted local operators
- private charters
- boat rentals
- sunset cruises
- dolphin tours
- seasonal water experiences

## Homepage funnel rules

The homepage should quickly route visitors into money pages.

**Above the fold should include:**

- clear headline
- short benefit-driven subheadline
- primary CTA to compare experiences
- secondary CTA to find the right experience
- visual trust/premium tourism feel

**Immediately below the hero, include clickable cards for:**

- Boat Rentals
- Sunset Cruises
- Dolphin Tours
- Nights of Lights Cruises

**Goal:** A visitor should be able to reach a monetizable page within 1 click and within 3 seconds.

## Money page routing

**Core money pages should be prioritized:**

- `/boat-rentals-st-augustine`
- `/sunset-cruises-st-augustine`
- `/dolphin-tours-st-augustine`
- `/nights-of-lights-boat-tours`
- `/fishing-charters-st-augustine`

Do not create many thin SEO pages at once. Prefer fewer, deeper, higher-quality pages.

**Every money page should include:**

- H1 targeting the main search intent
- short intro paragraph
- comparison cards
- “best for” positioning
- pricing/availability CTA
- trust block
- FAQ section
- related experience links
- affiliate disclosure

## Money page comparison card format

Each experience/operator card should include:

- experience/operator name
- short summary
- best for
- estimated duration, if known
- group size, if known
- highlights
- CTA button

**Preferred CTA:** Check Availability

## Internal linking rules

Every major page should link to related money pages.

**Examples — Boat Rentals page should link to:**

- Sunset Cruises
- Dolphin Tours
- Nights of Lights
- Fishing Charters

Blog/FAQ pages should link back to the most relevant money page.

Do not create isolated pages with no internal links.

## Trust rules

Every core page should reinforce trust.

**Use trust language like:**

- locally focused St. Augustine water experience guide
- curated recommendations
- compare options in one place
- seasonal recommendations
- transparent affiliate disclosure

**Include affiliate disclosure naturally:**

> Some featured experiences may earn us a commission at no extra cost to you. We only feature experiences we believe travelers will find useful.

Do not pretend to be the tour operator unless the site actually operates the tour.

## SEO rules

- Use one H1 per page.
- Use clean H2/H3 structure.
- Metadata should target transactional keywords naturally.

**Homepage title target:**

`St Augustine Boat Rentals, Sunset Cruises & Water Experiences | St Augustine On The Water`

**Homepage meta description target:**

`Compare St Augustine’s best boat rentals, sunset cruises, dolphin tours, fishing charters, and seasonal water adventures.`

- Use descriptive image alt text.

**Good alt text example:** `st augustine private boat rental at sunset`

**Bad alt text:** `hero image`

- Use WebP/compressed images when possible.

## Schema rules

Add schema where appropriate:

- Organization
- WebSite
- BreadcrumbList
- FAQPage
- TouristTrip or TouristAttraction only when appropriate

**Do not:**

- Use fake LocalBusiness schema unless the site is actually representing a real local business location.
- Use Review schema unless real review data is present and compliant.

## Mobile CRO rules

Most tourism traffic will be mobile.

**Prioritize:**

- fast load speed
- large tap targets
- visible CTA buttons
- short sections
- scannable cards
- minimal friction
- no cluttered layouts

Consider sticky mobile CTA only when it improves UX without feeling spammy.

Build topical authority slowly and intentionally.

**Priority content clusters:**

**Boat rentals:**

- boat rentals in St Augustine
- private boat rentals
- pontoon rentals
- family boat rentals
- captained boat rentals

**Sunset cruises:**

- sunset cruises in St Augustine
- romantic sunset cruises

**Dolphin tours:**

**Fishing:**

- fishing charters in St Augustine
- inshore fishing
- offshore fishing

**Seasonal:**

**FAQ content:**

## Important build principle

SEO matters, but **conversion matters more**.

A page is not done just because it has keywords.

A page is only useful if it:

1. matches search intent
2. builds trust
3. helps the visitor choose
4. routes the visitor toward a booking action

When making changes, always ask:

**“Does this make it easier for a visitor to find, trust, compare, and book a St. Augustine water experience?”**
